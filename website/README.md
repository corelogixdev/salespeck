# SalesPeck website

Marketing, sales, and support site for the SalesPeck desktop POS.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Cloudflare deploy via OpenNext (`npm run cf:deploy`)

## Local

```bash
cd website
npm install
npm run dev
```

Open http://localhost:3000.
